How to use this site

  1. Start with how much VRAM you have. It is the only hard constraint — the tiers that fit in 8GB and 24GB are entirely different. If VRAM is the limit, look at the "system memory / multi-GPU" columns in the same table — CPU-only or multi-GPU tensor parallel are viable routes.
  2. Use block B to filter file-size candidates. Then budget cache, concurrency and runtime; it is not an execution guarantee.
  3. Compare quantisers side by side in block C. See who covers the most tiers, who ships imatrix, and who is keeping up with releases.
  4. Read the per-tier detail in block D. Seven fields spell out what each variant is, how it differs, and when to pick it.
  5. Read the licence before downloading. Non-permissive licences are flagged; where a quant repo declares none, the page says "inherited from base" with the original link right beside it.
