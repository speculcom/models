What it fits / what it does not

Start here if

One of the strongest open-weight families for Chinese and code. Qwen4-Max is the closed-API flagship; the open-weight line remains Qwen3.8, and licence and hardware floor should be read separately.

Rule it out first if

要跑最大档（大杯 180B–2.4T：MoE 巨杯，需服务器级显存），显存和预算先按这一档估；小机器别拿最小档的体验代替。 许可含“other（Flash-Next 规格的许可以发布页为准）”，商用或再分发前先读原文；本页不替你判断。

Generations

  • Qwen4-Max2026-11current

    Released 2026-11-16: 2.4T total parameters, 71B active per token, native vision and 1M context; the closed-API flagship, with smaller Qwen4 models promised as open weights.

    official page ↗
  • Qwen3.82026-08

    Current generation. Three lines: 27B dense, 2.4T-A95B MoE, and Flash-Next (180B MoE). The 27B dense build is the most talked-about for local deployment.

    official page ↗
  • Qwen3.52026

    Architectural foundation of the previous generation — the official Qwen3.8 README states: "Built on the architectural foundation of Qwen3.5".

    official page ↗
  • Qwen32025-04

    Earlier flagship generation, spanning 0.6B to 235B-A22B; Apache-2.0 licensing and hybrid thinking modes were established here.

    official page ↗

Size tiers

  • Closed Max 2.4T: Qwen4-Max, 71B active, 1M context (API flagship)
  • Small 0.6B-9B: on-device, free tiers, CPU-capable
  • Medium 14B-35B: the local-deployment workhorse (27B dense leads this generation)
  • Large 180B-2.4T: MoE flagships needing server-class VRAM

Official capability claims (with sources)

  • Alibaba Group release: Qwen4-Max has 2.4T total parameters and activates only 71B per token, 25% fewer than Qwen3.8-Max; it supports a 1M-token context and native vision.source ↗
  • The vendor says Qwen4-Max ranks sixth on Code Arena and beats Qwen3.8-Max overall on Work360, using 35% fewer tokens in high-effort reasoning (vendor-reported, not independently reproduced).source ↗
  • Official README: Qwen3.8-27B is "a native vision-language model that understands images and videos", covering STEM diagrams up to hour-long video.source ↗
  • Official README: thinking mode is on by default and can be disabled per request, with reasoning depth tuned via reasoning_effort (stated for the hosted version).source ↗
  • The README's "1M context length by default" is a statement about the hosted service, not automatically the weights build; check config for the weights.source ↗

The above are quotations of official pages or transcriptions of vendor-run benchmarks; this site does not endorse cross-model conclusions.
