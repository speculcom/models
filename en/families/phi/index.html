Microsoft　·　current generation Phi-4-reasoning line（2026-08）

Phimodel family lineage card

Microsoft's small-but-high-quality line: MIT, sizes concentrated at 4B–15B, and the vendor's pitch is "teach small models with synthetic data". The current line is reasoning-vision (still a phi-4 post-train on the weight lineage). This site carries no quantisation comparison — the current generation's GGUF ecosystem is too thin (see below).

No quantisation comparison on this site: the current Phi-4-reasoning-vision-15B GGUF ecosystem measured only ~2.9k downloads (HF search 2026-10-30), far below the ~300k threshold; the older phi-4 / mini ecosystems are larger but are not the current generation, and this site does not collect older generations (collection rule #1).

    official page ↗

Derived from per the official model-card base_model declaration

The official model card declares the current-generation Phi-4-reasoning-vision-15B is based on Phi-4-reasoning, which in turn declares phi-4 as its base (SFT + RL fine-tuning) — the whole current line is a post-train lineage of phi-4, not trained from scratch.　base：microsoft/Phi-4-reasoning　source ↗
