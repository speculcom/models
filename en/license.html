Licence quick reference

Open source is not free-for-all: four questions first

This quick reference splits model-weight and tool licences into four questions: commercial use, attribution, user-scale thresholds, and distillation/derivatives. It translates fields and quotes the original; it does not make a legal judgment.

33 licence recordsVerified 2026-11-25Not legal advice

Start with four questions

“Commercial use” is only the first gate

1. Can it be used commercially?

Apache and MIT usually allow it; AGPL allows it but adds an open-source obligation; vendor-specific licences (other/OpenMDW) must be read in full.

2. Is attribution required?

MIT and Apache require keeping the copyright and licence notices; some vendors also require attribution in user documentation. Removing notices before commercial use is the most common mistake.

3. Is there a user-scale threshold?

Some “open” licences require a separate commercial licence above a MAU or revenue threshold. Where no threshold is found, this page says “not found”, not “none”.

4. Is distillation or derivation allowed?

Permission to modify code does not automatically permit using outputs to train another model. Distillation clauses must be read separately; this page does not expand a vendor licence.

Filter

Narrow by how you use it

Different uses trigger different clauses: internal use looks at commercial rights and data retention; delivery to customers looks at redistribution and liability; open-sourcing looks at attribution and open-source obligations; public SaaS also looks at MAU thresholds, filing and content safety. If nothing matches, relax one condition; do not treat “unknown” as “allowed”.

Three boundaries

Do not conflate three different things

Weight licence ≠ service terms

Downloading weights is governed by the model-card licence; calling a vendor API or web product is governed by the service terms. The two can differ completely.

Base licence ≠ quantised-repo licence

Third-party GGUF quantisation repos usually inherit the base licence, but the quantiser may add its own notice. Read the release page together with the base licence.

Licence permission ≠ local compliance

A model being commercially licensed does not mean it can be offered as a public generative service in a given jurisdiction. Filing, safety assessment and content labelling are separate requirements.

This page is not legal advice. For material commercial, redistribution or distillation decisions, have legal counsel read the licence text and the contract; this page only helps you ask the right questions.
