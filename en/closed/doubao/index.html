ByteDance · Volcengine　·　closed model lineage card　·　current generation Doubao-Seed 2.1 line (Pro / Lite / Seed-Evolving) + SeedRealtime 1.0（2026-11）

Doubao (closed API)closed model · official spec snapshot · with review cycle

The domestic closed flagship: the Doubao consumer app and the Doubao-Seed API are two lines of one family; the service is CAC-filed (Beijing-YunQue-20230821 — Doubao LLM is the renamed YunQue, confirmed on the official filing-disclosure page). Generations churn fast, so the card carries a check date and review interval.

How you can use it：Volcengine Ark API and the Doubao app; weights are not open.

No open weights, no quantisation coverage; the three-essentials light entry for the app lives on the tools site (chat section).

China availability domestic / direct access / CAC filing · snapshot 2026-10-20

  • Origin　domestic　Made by ByteDance (Beijing).
  • Direct access　direct OK　Volcengine and Doubao sites reachable direct from the mainland (measured 200 on 2026-10-30).
  • CAC filing　Filed：Beijing-YunQue-20230821　listed as「云雀（豆包大模型）」　·　filed 2023-08-31　·　Filed in the first batch (row 3 of the public list: “YunQue model · Beijing Douyin Information Service Co.”); Doubao’s official filing page confirms Doubao is YunQue (Beijing-YunQue-20230821).

Filing status is quoted from the CAC public registry by number. "Direct access" means the page opened once from a mainland network — not a vendor promise.

Official spec facts (each with a source) as of

  • Context window　2.1-pro-260915 / 2.1-lite-260915: 1024k input; 2.1-pro supports 256k max output and 256k max thinking (Volcengine Ark model detail)source ↗
  • Pricing pointer　Billed by tier and usage; this site does not copy numbers — see the official pricing table.source ↗
  • Input modalities　Text, image and video input; 2.1-lite natively unifies text, vision and audio understanding (Volcengine release announcement)source ↗
  • What changed　The 0915 release strengthens long-horizon agent execution, multimodal coding and multimodal understanding; the November Seed-Evolving update focuses on multi-step planning, result acceptance, tool use and factual consistency, with lower latency and cost per call (Volcengine announcement)source ↗
  • Sibling generation lines　Seedream 5.5 (image) and Seedance 2.5 Flash (video) went live on 2026-11-18; Seedance 2.5 Flash supports up to 30s, 480P/720P, and up to 10 images + 5 videos + 5 audio references (Volcengine model marketplace)source ↗
  • Realtime audio-video line　Doubao-Seed-Realtime 1.0 went live in the API on 2026-11-19: full-duplex, end-to-end, natively fusing audio, video and text; clients can push camera / screen frames at up to 2 FPS so the model can resolve references and track scene changes (Volcengine Doubao Voice product page / Android SDK docs).source ↗
