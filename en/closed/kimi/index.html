Moonshot AI　·　closed model lineage card　·　current generation Kimi K3.1 Pro (3T-class, 1M context)（2026-10）

Kimi (closed API)closed model · official spec snapshot · with review cycle

The domestic closed flagship — yet the only family here with dual tracks: K3 weights are open on Hugging Face / ModelScope (custom Kimi K3 License) while the API runs on platform.kimi.com. Licences and data terms differ between the two paths — read them separately.

How you can use it：platform.kimi.com API and the Kimi app; K3 weights are also open (see the kimi family card on the open-weight side) — API and open weights are two usage paths to the same model.

On the open-weight side this site covers the kimi-k3 series (family card + quantisation); the chat light entry lives on the tools site.

Official spec facts (each with a source) as of

  • Scale and context　3T-class parameters; 1,048,576-token context; thinking mode only (official Kimi announcement and Kimi Code docs)source ↗
  • Thinking effort　reasoning_effort supports low / high / max, default high; disabling thinking returns 400 (Kimi Code docs)source ↗
  • Weight release　Full model weights to be released by 2026-11-04 (official announcement; at launch on 10-24 the date was stated as “by Nov 4”)source ↗
  • Official benchmarks　Terminal-Bench 4.0 65.7%, above GPT-6 Astra at 58.2% and slightly below Claude Opus 5.5 at 66.4%; Kimi Code Bench 3.0 Long-horizon 61.2% (official tech blog, vendor-reported)source ↗
  • Highspeed variant　K3.1 Pro Highspeed keeps the same intelligence at roughly 2–3x output speed and about 2x the token consumption (official announcement)source ↗

The above transcribe official docs and release pages; vendors may have changed specs since. For pricing, use the official pricing page linked below.
