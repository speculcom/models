Alibaba Cloud / Alibaba　·　closed model lineage card　·　current generation Qwen4-Max (2.4T, 1M context, native vision)（2026-11）

Qwen (closed API)closed model · official spec snapshot · with review cycle

The largest domestic closed flagship by parameter count, running in parallel with an open-weight line: Max stays on the API while smaller Qwen4 models are promised for open source. Read API terms and the future open-weight licence separately; they are not one model.

How you can use it：QwenCloud and Alibaba Cloud Model Studio API; Qwen4-Max and Qwen3.8-Max run through the closed API, while smaller Qwen4 family models are promised for open source (official blog).

On the open-weight side this site covers the qwen3-8 series (family card and quantisation comparison); Qwen4-Max is API-only today, so local quantisation does not apply.

China availability domestic / direct access / CAC filing · snapshot 2026-11-19

  • Origin　domestic　Made by Alibaba (Hangzhou).
  • Direct access　direct OK　QwenCloud and Alibaba Cloud Model Studio are reachable direct from the mainland (200 on recheck, 2026-11-19).
  • CAC filing　filing unknown：The filing number for the Qwen4-Max product name was not located item by item in the public list; the parent Alibaba Cloud is filed. No number is invented.

Filing status is quoted from the CAC public registry by number. "Direct access" means the page opened once from a mainland network — not a vendor promise.

Official spec facts (each with a source) as of

  • Parameter scale　2.4 trillion total parameters (Qwen4-Max, official release); 71B active per token, 25% fewer than Qwen3.8-Max.source ↗
  • Context window　1,000,000 tokens (Qwen4-Max, official release)source ↗
  • Input modalities　Native vision plus text; the official model docs say it handles image and video understanding (official model docs)source ↗
  • Pricing pointer　Billed through Token Plan or API usage; this site does not copy numbers — see the QwenCloud pricing page.source ↗
