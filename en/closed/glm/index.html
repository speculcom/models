Z.ai (Zhipu AI)　·　closed model lineage card　·　current generation GLM-5.4 (750B base, vendor-claimed 2–3T-class intelligence)（2026-11）

GLM (closed API)closed model · official spec snapshot · with review cycle

GLM-5.4 is a closed-first release with open weights pending. Coding Plan users can use it in supported tools now, while the public API and weights are still pending; for local deployment, still use 5.3 and the MIT-licensed Flash tier.

How you can use it：z.ai / BigModel APIs (GLM-5.3 and earlier); GLM-5.4 is already available to all GLM Coding Plan users in supported tools, while the public API awaits safety assessment and weights are planned after safety hardening — no download or local deployment today.

The open-weight glm-5 family card still tracks GLM-5.3 (with quantisation comparison); 5.4 is recorded here and on the 2026 supplement page.
